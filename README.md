### 🚀 Пет-проекты (Research & Development)

**📝 CRM Агенства недвижимости (AI-приоритизация)**
*   **Суть:** Full-stack проект CRM для агентства недвижимости с **fine-tuned ruBERT-tiny2**: модель классифицирует текст обращения клиента на три уровня срочности (low / medium / high), rule-based NLP извлекает критерии поиска, scoring ранжирует объекты для менеджера.
*   **Реализация:** Дообучил модель ruBERT-tiny2 (accuracy **96.8%**, macro-F1 **96.8%** на validation) на сгенерируемом датасете в формате `.tsv` и интегрировал её в CRM-систему. Во время инференса модель правильно категоризировала low и high приоритеты, но medium в большинстве случаев зависел только от срока, который указал покупатель в тексте заявки. Веб-приложение разработал с помощью современных инструментов.
*   **Стек:** `Python`, `DJango`, `transformers`, `PostgreSQL`, `React`, `TypeScript`
*   **Ссылка:** [Репозиторий проекта](https://github.com/Vihhycherezass/estateflow-ai-crm)

**⚖️ RAG-ассистент по Трудовому кодексу РФ (RAG Labor Code RU)**

* **Суть:** Локальная гибридная RAG-система, которая находит релевантные статьи Трудового кодекса РФ и генерирует юридические ответы со ссылками на использованные источники.
* **Реализация:** Реализовал обработку PDF по статьям, dense retrieval на multilingual E5 и BM25 с объединением через RRF, CrossEncoder reranking и генерацию локальной Saiga/Mistral 7B. Добавил NeMo Guardrails, защиту от prompt injection, Gradio-интерфейс и GPU-оптимизацию для NVIDIA T4.
* **Стек:** `Python`, `LlamaIndex`, `Sentence Transformers`, `BM25`, `llama.cpp`, `Saiga/Mistral`, `NeMo Guardrails`, `Gradio`
* **Ссылка:** [Репозиторий проекта](https://github.com/Vihhycherezass/RAG-Labor-Code-RU)
